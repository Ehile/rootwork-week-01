Part 4: Test Cases

The following test cases cover the required scenarios. Each test uses the same decision rules, with different applicant values.

Test 1: Applicant younger than 18
Input: age = 17, score = 90, hasLaptop = true, hasInternet = true, completedApplication = true
Expected result: Not eligible
Actual result: Not eligible
Reason: The applicant is younger than 18, even though the score is high.


Test 2: Score below 60
Input: age = 21, score = 55, hasLaptop = true, hasInternet = true, completedApplication = true
Expected result: Not eligible
Actual result: Not eligible
Reason: The score does not meet the minimum requirement.


Test 3: No internet access
Input: age = 22, score = 90, hasLaptop = true, hasInternet = false, completedApplication = true
Expected result: Not eligible
Actual result: Not eligible
Reason: Internet access is compulsory.


Test 4: Incomplete application
Input: age = 25, score = 88, hasLaptop = true, hasInternet = true, completedApplication = false
Expected result: Not eligible
Actual result: Not eligible
Reason: The application has not been completed.


Test 5: No laptop access
Input: age = 20, score = 85, hasLaptop = false, hasInternet = true, completedApplication = true
Expected result: Not eligible
Actual result: Not eligible
Reason: The applicant does not have laptop access.


Test 6: Applicant aged exactly 18
Input: age = 18, score = 70, hasLaptop = true, hasInternet = true, completedApplication = true
Expected result: Eligible
Actual result: Eligible
Reason: The minimum age requirement is 18, so an applicant aged exactly 18 qualifies if all other normal requirements are satisfied.


Test 7: Score exactly 60
Input: age = 19, score = 60, hasLaptop = true, hasInternet = true, completedApplication = true
Expected result: Eligible
Actual result: Eligible
Reason: A score of exactly 60 meets the minimum score requirement but is below the priority threshold.


Test 8: Priority candidate
Input: age = 24, score = 90, hasLaptop = true, hasInternet = true, completedApplication = true
Expected result: Priority candidate
Actual result: Priority candidate
Reason: The applicant satisfies every normal requirement and has a score of at least 85.
